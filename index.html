    Install as an app

      Operating the optics

      • Tap a bracket — lock onto that object. Tap again to release.
      • Double tap a bracket — spoken readout of class, confidence and proximity.
      • Hold anywhere — full situation report, spoken aloud.
      • Tap empty space — wide rescan sweep.
      • Swipe up from the bottom — open configuration.

      Voice commands enable MIC

      • “status” / “what do you see” — situation report
      • “lock onto the dog” — acquire a named class
      • “stop tracking” — release the lock
      • “snapshot” — store a captured frame
      • “torch” — toggle the illuminator (if fitted)
      • “flip camera” — switch optics
      • “mute” / “talk to me” — audio control
      • “stand down” / “wake” — halt and resume inference
      • “full scan”, “help”, “palette green”

      How it works

      Each frame from the camera is letterboxed to an aspect-correct tensor and pushed through a YOLOv8-nano convolutional network via onnxruntime-web — WebGPU where the handset supports it, otherwise multi-threaded WebAssembly. The anchor-free head emits 84 × N values per frame (4 box coordinates plus 80 class scores), which ARGUS decodes, filters with class-wise non-maximum suppression, then matches against the previous frame with an intersection-over-union tracker. Stable identities are what make the brackets stop flickering and let the assistant talk about “that object” over time.

      Proximity estimates

      This model has no depth output. The NEAR / MID / FAR chips are derived from how much of the frame an object occupies — a monocular size proxy, not a metric distance.

      Performance notes

      • INF in the telemetry block is the neural inference rate — the number of full scene analyses per second. The overlay itself redraws every display frame, so the brackets stay smooth even when the analysis rate is low.
      • Warm the app for 10–15 seconds: the first frames are slower while the graph compiles and the GPU pipeline ramps.
      • WebGPU gives the smoothest overlay. If the HUD stutters, force the WASM backend in configuration.
      • Bright, high-contrast scenes detect best; the network was trained on COCO photographs.
      • Long sessions get warm. Standby halts inference instantly.

      Privacy

      The neural core, the runtime and every asset are stored locally and served by the app's own service worker. There is no analytics, no upload path and no third-party script: the only network request is the initial installation of the files.
